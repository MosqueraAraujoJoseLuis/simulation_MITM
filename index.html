Classification des Risques de Sécurité

Faible
  • Eve intercepte les données, mais ne peut pas les lire;
  • les modifications sont détectées;
  • les clés sont fortes et secrètes;
  • les clés publiques sont vérifiées.
Moyen
  • une mauvaise configuration peut faciliter une attaque;
  • une clé ou une valeur utilisée est prévisible;
  • certaines informations sont accessibles à Eve.
Élevé
  • une clé faible est utilisée;
  • une clé publique n’est pas vérifiée;
  • l’intégrité n’est pas protégée;
  • Eve peut tenter un nombre limité de possibilités.
Critique
  • Eve possède la clé secrète ou privée;
  • Eve peut lire le message;
  • Eve réussit une attaque MITM;
  • Eve peut modifier le message sans être détectée;
  • Eve peut se faire passer pour Alice ou Bob.
